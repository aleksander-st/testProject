# Создание сервера

- Роут: `/servers/create`
- Figma: `Screen/ServerCreate` (`89:209`)
- Компоненты базы: `ProductHeader`, `Breadcrumb`, `OptionCard`, `Select`, `Input`, `Button`
- Локальные композиции: `SectionHeading`, `RegionOption`, `PlanCard`, `ServerSummary`
- Мок-данные: ОС, регионы, тарифы, SSH-ключи, баланс и прогноз приходят из `src/data/`
- Поведение: выбранные опции обновляют сводку; имя валидируется; submit показывает loading, создаёт сервер, списывает баланс и возвращает на Dashboard
- Edge-cases: пустое/длинное/невалидное имя, дубликат имени, недостаточный баланс
- Адаптивность: при сужении правая сводка переносится над формой, сетки ОС и тарифов переходят с четырёх/трёх колонок на две и одну
