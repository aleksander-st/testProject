# Mock prototype data

Единый слой данных интерактивного прототипа из `directive_wire.md`.

- `mockData.ts` — исходные серверы, операции и опции формы
- `PrototypeStore.tsx` — изменения баланса, создание и управление серверами
- `PrototypeStoreContext.ts` — доступ экранов к одному состоянию
- `types.ts` — доменные типы

## Основной сценарий

`/dashboard` → «Создать сервер» → `/servers/create` → submit → новый сервер со статусом «Деплой» на дашборде → «Детали».

## Проверяемые состояния

- Loading: создание, перезагрузка одного сервера и всех серверов
- Success: Toast после успешного действия
- Error: дубликат имени существующего сервера
- Validation: пустое, длинное или не соответствующее slug-формату имя
- Empty: пустые события нового сервера и незаполненные вкладки деталей; пустой список серверов предусмотрен в Dashboard
- Low balance: предупреждение и блокировка создания, если цена тарифа выше баланса

Данные живут только в памяти вкладки и сбрасываются при полной перезагрузке — бэкенд и API не подключены.
